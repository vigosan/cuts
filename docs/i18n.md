# Idiomas

Idiomas de la app: **inglés (`en`)** y **español (`es`)**. El idioma de reserva es el inglés.

- Todas las cadenas visibles (interfaz, menús, diálogos, errores, textos de accesibilidad y "Acerca de") están en `apps/desktop/src/shared/i18n.ts`, como frases completas.
- La interfaz elige el idioma con `navigator.languages`, y el proceso principal con `app.getPreferredSystemLanguages()`. Ambos siguen el orden de preferencias de macOS y se quedan con el primer idioma soportado.
- Los plurales usan `Intl.PluralRules` y los decimales `Intl.NumberFormat` (por ejemplo, "0,5 s" frente a "0.5 s").
- El paquete solo incluye las carpetas `.lproj` de inglés y español (`electronLanguages` en `apps/desktop/electron-builder.yml`), para que la App Store anuncie solo esos idiomas.

Las traducciones al inglés las escribió el desarrollador; **no las ha revisado una persona nativa**.

## Añadir un idioma

1. En `apps/desktop/src/shared/i18n.ts`, añade el código a `Locale` y a `SUPPORTED_LOCALES`.
2. Copia la función `spanish` como, por ejemplo, `french`, traduce cada frase y regístrala en `builders`. TypeScript avisa si falta alguna clave, y la prueba "translates every message into every supported language" también.
3. Añade las variantes `.lproj` del idioma a `electronLanguages` en `apps/desktop/electron-builder.yml` (por ejemplo, `fr`, `fr_FEMININE`, `fr_MASCULINE` y `fr_NEUTER`).
4. Ejecuta `make test` y abre la app con `"/Applications/Cuts.app/Contents/MacOS/Cuts" -AppleLanguages "(fr)"` para revisar textos largos y truncados.

## Textos sin localizar

- Nombres de marca y técnicos: "Cuts", "FFmpeg", "Finder" y "4:5 · 1080×1350". Se mantienen igual.
- Errores que devuelve FFmpeg: se muestran tal cual, en inglés, detrás del mensaje localizado ("Falló el clip 1: …").
- Errores del sistema de archivos: el código (`EPERM`, `ENOSPC`…) aparece en inglés detrás del mensaje localizado.
